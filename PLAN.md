# The tool

Write a tool to easily parse and summarise the swagger spec for pracbill.json

# The goal

Write a Windsurf compatible MCP server that can be used to interact with the Pracbill API. Utilize the tool to extract/parse/understand the swagger spec and generate appropriate MCP tools.

# IMPORTANT

Accept the Pracbill URL and API credentials as an environment variable.
Provide documentation for how to use the MCP server, and how to install it in a variety of AI IDE's.

Always be comprehensive and support all endpoints in the swagger spec.

Write industry standard, hardened code with comprehensive error handling and logging.
